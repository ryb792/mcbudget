# 省钱模式

仅在用户要更便宜、自动领券、积分换券或比较活动优惠时扩展普通预算流程。能力来源：[麦当劳官方工具列表](https://github.com/M-China/mcd-mcp-server#3-工具列表)。参数以当前连接实际 schema 为准，不猜商城商品 ID、字段或兑换返回结构。

## 优先顺序

1. **已有券与菜单促销。** 使用当前门店 `query-store-coupons` 和 `query-meals` 返回的真实可用项，优先比较默认套餐、券商品与普通商品。划线价、券标题和宣传“省多少”不能代替 `calculate-price`。
2. **免费券自动领取。** 用户说“先自动领免费券再点餐”“帮我领券”，或已明确开启自动领券偏好，视为授权本次免费券领取；调用一次 `auto-bind-coupons` 即领取全部当前可领券，无需逐张确认，也无需先查一遍列表。普通预算请求未授权时沿用已有券。询问有哪些券时才 `available-coupons`。领取完成后重新查门店券，废弃旧报价；本会话不因每次改预算重复领取。结果不明确时先查我的券核实，不循环重复领券。
3. **积分换餐品券。** 用户询问积分或希望进一步减少现金支出时，读 `query-my-account`，再按实际 schema 查询 `mall-points-products`；只对与本餐匹配的少量餐品券读 `mall-product-detail`。优先看可用积分、即将过期积分，以及商品积分成本、额外现金、数量、有效期和适用条件。普通快速推荐不默认查商城全量商品。
4. **活动与用餐方式。** 用户愿意比较活动时才 `campaign-calendar`。活动日期、门店、餐品和适用方式需实际可用；不得把未来活动当成当前报价。只有用户愿意更换方式时才比较到店与外送，计入配送、打包和餐具费；更换后重新构建该方式上下文。

## 积分兑换与使用

积分是独立成本，不自动折算人民币，不将积分换券描述为“完全免费”。本预算流程只纳入**纯积分、额外现金为 0** 且适合本餐的券，给用户一个简短选择：“这张餐品券需 X 积分，无额外现金，有效期至 Z；要兑换吗？”数值来自真实详情。积分上限还需核对实际可用余额，不把用户提到的积分数当账户余额保证。

商城现金成本不在餐饮 `calculate-price` 中，不能遗漏。带现金的商城商品不默认兑换；用户主动要购买时须明确商城现金和餐饮现金的合计预算，取得额外购买授权，分别列出成本，不能只按餐饮报价宣称原预算内。无法可靠核对总成本或存在未知收费时，不把该商品用于预算挑战。

确认具体商品、数量、积分及现金成本后，按真实 schema 调用 `mall-create-order`；已给出的明确兑换授权与积分上限不重复询问。兑换会扣减积分，兑换订单与餐饮 `create-order` 是两种操作。未确认可用于本次用餐的券不为了试价格先兑换；已授权并成功兑换后，通过返回结果及 `query-my-coupons` / `query-store-coupons` 核实到账和门店适用性，再构建完整券商品购物车、官方核价并更新餐单。

兑换超时或结果不明确时不自动重复兑换：用 `mall-order-list`，有订单号时用 `mall-order-detail` 核实。若实际工具缺失或详情不足，说明当前不能完成，提供麦当劳 App 手动兑换路径，待券到账后继续；不编造兑换成功、积分余额或优惠金额。

## 比较与预算

同一餐品或满足用户需求的替代方案，比较成功官方报价中的**最终现金应付**，包括配送、打包、餐具及实际参与费用。组合不能凭券面金额直接相减；多券是否可叠加由完整购物车的官方核价决定。餐品替换或套餐减配需符合用户的口味、必选项与数量要求。

保持默认 6 个核价目标；优先把真实适用的套餐/券商品作为候选，不为每张券分别跑一轮。需要更广比较时最多扩展到 12 个，复用本轮已成功的完整购物车报价。不要把没有适配到完整购物车的券硬套在原商品上。

本轮已核价的同餐品比较证实更便宜时，简短说明“已用可用优惠，实付 ¥X”。只有同一上下文、同一内容存在真实前后报价时才写“少付 ¥Y”；缺少对照就不制造节省金额。常规推荐仍按预算内偏好、套餐和覆盖度排序；用户明确优先最低现金支出时，将其要保留的餐品要求设为必选项、排除要求保留，设置 `ctx.selection="lowest_cash"`。从满足这些硬性要求的成功核价候选中按现金应付优先，口味软偏好仅用于同价排序，并标明此轮候选范围；用户要求保留餐品时不能换成更便宜但不满足要求的商品。

购买麦金卡/早餐卡会产生额外支出，只有用户主动要求比较或购买时才按真实 `withOrder` 和官方总价评估；不默认购卡凑优惠。`draw-lottery` 消耗积分且结果不确定，不作为默认省钱步骤。不为得到宣传折扣增加用户不需要的商品或超预算。
