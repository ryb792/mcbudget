项目名称：麦麦预算挑战 McBudget
项目地址：https://github.com/ryb792/mcbudget
项目简介：面向普通办公用户的 WorkBuddy Skill。输入预算和口味，生成 B-5/B/B+5 三档配餐方案，解释增减预算带来的餐品与实付变化，并导出 PNG 挑战卡。提供无需 Token 的本地演示；真实模式结合麦当劳 MCP 的门店、菜单、优惠、算价及订单工具，先核价、确认后下单，支付由用户完成。已完成真实门店、菜单和官方算价的只读验证；领券、创建订单与支付未实测并在文档中注明。包含参赛声明、接入说明、脱敏配置示例、源码和 WorkBuddy 开发摘要。
