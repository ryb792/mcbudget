项目名称：麦麦预算挑战 McBudget
项目地址：https://github.com/ryb792/mcbudget
项目简介：面向普通办公用户，适用于 WorkBuddy、Codex 等支持 Skill 与 MCP 的工具的通用 Skill。输入预算和口味，基于真实门店、菜单与官方核价生成 B-5/B/B+5 三档配餐方案，解释增减预算带来的餐品与实付变化，并导出 PNG 挑战卡。用户请求或确认后领券，选定方案重新核价、确认后下单，支付由用户完成。已有门店、菜单和官方算价的只读实测记录；开发者补充确认领券、创建订单与后续支付流程测试可行。发布包仅用于真实 MCP 使用，GitHub 保留独立的无需 Token 网页演示。包含参赛声明、接入说明、脱敏配置示例、源码和 WorkBuddy 开发摘要。
