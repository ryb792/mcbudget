项目名称：麦麦预算挑战 McBudget
项目地址：https://github.com/ryb792/mcbudget
项目简介：面向普通办公用户，适用于 WorkBuddy、Codex 等支持 Skill 与 MCP 的工具的通用 Skill。输入预算和口味，基于真实门店、菜单与官方核价生成 B-5/B/B+5 三档餐单与增减解释，按需导出 PNG 卡。默认最多核价 6 个候选，可扩展到 12 个；改预算优先复用有效报价本地重排。可选省钱模式，授权后每个会话最多领取一次免费券；只读比较积分餐券，确认商品、积分与数量后兑换，再核实门店可用性并核价。选定方案重新核价、确认后下单，简洁交付餐品、金额、收餐信息及支付链接，支付由用户完成。已有门店、菜单和官方算价的只读实测记录；开发者补充确认免费领券、餐饮订单与支付流程可行，积分兑换不计入该实测确认。发布包仅用于真实 MCP 使用，GitHub 保留独立的无需 Token 网页演示。包含参赛声明、接入说明、脱敏配置示例、源码和 WorkBuddy 开发摘要。
