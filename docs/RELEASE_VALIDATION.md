## v0.3.1 减少等待（2026-10-11）

- 默认官方核价候选上限从 12 个降为 6 个；短名单覆盖三个预算档及较低估算候选，扩展至 12 个时前六项一致。估算仍不参与真实推荐或金额判断。
- 新增 `plan_quotes` 直接规划待核价购物车，以及 `select_priced_ladder` 用已核对上下文的成功官方报价本地重选；不再要求先用空回调执行一遍完整引擎。
- 仅调整预算时优先复用本会话仍有效的报价；核对完整购物车、账户、门店、方式、时段和券状态，展示复用最长 5 分钟。下单前重新核价与确认保留。
- 工具发现、连接探测、门店查询与详情读取按需复用；独立只读查询可有限并行，卡片和二维码按用户请求生成。普通点餐不运行开发者冒烟检查、回归测试或打包。
- 新增 `QuoteBatchAborted` 中止整批连接故障，保留之前成功的报价，避免持续等待；只读检查脚本增加核价上限、可配置超时与各工具耗时记录。
- 108 项原 Python 回归、65 项性能与选餐策略回归通过，合计 173 项；4 组 Python/JavaScript 独立网页演示一致性通过。性能检查覆盖三档结果、低价回退、6→12 前缀、零新增核价的预算调整、无效报价拒绝、故障中止与最低现金策略。
- 106 项合成菜单离线压力测：候选 30 个，默认报价回调 6 次；本次本机计算中位数约 628 毫秒，本地预算重选约 630 毫秒。这些数据仅反映本地 Python 计算，不包含真实 MCP、网络或客户端等待；不据此承诺总耗时的提升比例。
- 独立 Skill 演练检查了改预算、领券后下单及首次未连接三种场景；已报价时间保留、券变化使旧报价失效、最终重新核价确认的行为保持。
- 增加按需省钱说明：授权后每会话领取一次免费券，积分商品先查询成本与适用条件，再按授权兑换；积分和现金分别展示，不默认购卡或抽奖。依据官方工具列表，未把积分兑换描述为已实测。
- 预算挑战优先只纳入无额外现金的积分券；商城现金不包含在餐饮算价内，带现金的商城购买需明确合计预算与额外授权，不把单独餐饮报价误当全部支出。最低现金策略先满足必选及排除要求，再按官方实付升序，软偏好只处理同价。
- 下单结果只显示餐品摘要、最终应付、收餐信息和支付入口；内部核对保留，原始订单字段及重复金额明细不默认展示。
- 技能包含 16 个真实运行资源（新增省钱参考），解压后可独立导入；配置、文档链接和资源与源码一致性检查通过，包内无演示或性能测试资源。源码和解压包的 Skill 格式检查通过。
- 本次验证未读取个人 MCP 凭据或访问餐饮服务，未领取券、创建餐饮订单或支付。既有真实链路的开发者确认仍见 MCP 接入说明，不改写历史记录。
